Gnosis Chain + Ledger + Safe{Wallet} Architecture

Production deployment checklist for Gnosis Mainnet (100) & Chiado Testnet (10200)

1. Physical Ledger + Safe{Wallet} Setup (External Action Required)

Hardware wallets must be ordered directly from Ledger's official store and initialized offline by you. Once initialized, open app.safe.global on Gnosis Chain (Chain ID 100) and create a 2-of-3 Safe with your Ledger addresses.

2. Deploy TStreetToken.sol & TStreetDealEscrow.sol

Compile with Solidity ^0.8.24 (Foundry / Hardhat) and pass your Gnosis Safe address as initialSafeGovernor, initialSafeTreasury, and initialSafeArbiter.

3. Continuous Self-Hosted Control Plane + GitHub CI

GitHub Actions runs automated verification (.github/workflows/tstreet-ledger-ci.yml) on every push/PR, while this self-hosted tstreet_ledger.server daemon provides 24/7 sequencing, expiry sweeps, and invariant circuit-breaker monitoring on your own server or container.
